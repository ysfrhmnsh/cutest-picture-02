# Milo Plays with Yarn — cutest-picture-01 (entry 2)

Second entry for the make.fun bounty "Make the cutest picture": a program
that draws a fluffy cream kitten sitting on a pink rug in a lavender
garden, one paw raised batting at a big coral ball of yarn, its green eyes
looking up at the ball, a loose string dangling to the floor and its tail
curled on the grass. A tiny lavender bow, a pink butterfly and daisies
complete the scene.

Pure Python 3.13 standard library (math, os, struct, zlib), self-written
PNG encoder, no network, no model calls, no clock, no unseeded randomness.
Two runs write byte-identical output (sha256 in BUILD_NOTES.md).
